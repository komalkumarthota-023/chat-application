## Project Overview

This is a beginner-friendly chat application created completely using Python.
The program runs in the terminal and allows the user to send messages and receive simple bot replies.

The main purpose of this project is to understand:

Python basics
Loops
Lists
Conditions
User input handling

This project is simple and easy to understand for beginners and internship projects.

## Technologies Used
Python

## Features
User can type messages
Bot gives instant reply
Stores chat history
Exit option using exit
Beginner-friendly code structure
